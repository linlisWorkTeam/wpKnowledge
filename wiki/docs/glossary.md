# 名词表（Glossary）

> 最后更新：2026-08-20

| 术语 | 英文 | 含义 |
|------|------|------|
| 知识飞轮 | Knowledge Flywheel | 源码 → 知识 → 代码 → 反馈 → 知识优化的循环 |
| 知识文档 | Knowledge Document | 基于源码反推的解释型 Markdown 文档 |
| 知识生成 | Knowledge Generation | Skill 基于源码生成知识文档 |
| 代码生成 | Code Generation | Agent 基于知识文档编写代码 |
| 差异对比 | Diff & Analysis | Agent 生成代码与原始源码的对比分析 |
| 反馈优化 | Feedback Loop | 将差异作为反馈返回，优化知识 |
| 门禁 | Gate | 知识质量评测阈值机制（如 80% 相似度） |
| 主力路线 | Main Track | 四步飞轮循环（当前主线） |
| 备选路线 | Backup Track | 破坏源码 → Agent 补齐（能力补齐，非主线） |
| GLM 5.1 | — | 公司本地部署的模型，飞轮唯一可用模型 |
