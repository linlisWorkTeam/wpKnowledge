# TASK：WorkPanel 调研知识库

## 目标

持续研究 LinlisWorkPanel 的产品定位、系统架构、工程质量及其与主流 Agent CLI、Harness 和多 Agent 协作平台的差异。

## 范围

- LinlisWorkPanel 前端、Rust 后端、调度器、适配器、SQLite、扩展宿主和发布体系。
- Claude Code、OpenCode、DeepSeek Harness、Clowder-ai 等对比对象。
- 可执行的架构改进建议、优先级和演进记录。

## 交付约定

1. 正式报告放在 `docs/`，过程证据放在 `notes/`。
2. 每份报告注明日期、目标 commit、验证命令与外部来源。
3. 明确区分已验证事实、源码推断和建议。
4. 不在知识库中保存 API Key、令牌、私有数据库或用户隐私数据。
