# Wiki · 知识飞轮项目

> 从超大代码库（单仓 30 万行、总量上亿行）反推高质量知识文档，构建"源码 → 知识 → 代码 → 反馈"的知识飞轮。

## 📂 目录

| 目录 | 内容 |
|------|------|
| [docs](设计/) | 项目正式文档：知识形态、飞轮设计、门禁标准 |
| [research](研究/) | 调研材料：论文、开源项目、笔记 |

## 🎯 项目一句话

用 Skill 从源码反推**解释型 Markdown 知识**，让 Agent 基于知识重新生成代码，通过与源码的差异对比形成反馈闭环，持续优化知识质量，直到通过门禁阈值（如 80% 相似度）。
