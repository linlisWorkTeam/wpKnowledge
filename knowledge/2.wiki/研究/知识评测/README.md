# 知识评测

判断知识对不对这一段的调研材料。对应 `evaluation` 阶段的门禁判定与 `testGenAgent` 的测试生成，是「评测产出事实、飞轮决定下一步」里的判定侧。

星级按**对本项目的可落地程度**评定，不按论文本身影响力。五星表示可直接指导实现决策。

## 怎么用这批材料

- **要设计门禁**：门禁自博弈风险、变异测试、执行式评测三篇是基础
- **要提升测试集强度**：EvalPlus、覆盖率引导、变异测试三篇给出具体手段
- **要防评测失效**：CodeJudgeBench、防污染、语义等价三篇覆盖判官偏差与污染
- **要判断门禁可信度**：门禁自博弈风险与自进化 Agent 脆弱性两篇合看，前者讲结构隔离，后者讲统计稳定性

门禁设计详见 [`../../设计/门禁与评测机制.md`](../../设计/门禁与评测机制.md)。
评测选型结论见 [`../../设计/评测的选型调研报告.md`](../../设计/评测的选型调研报告.md)。
