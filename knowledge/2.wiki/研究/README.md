# 研究 · 知识飞轮调研材料

研究材料按主题组织。每篇材料记录来源、置信度、核心方法、局限和对本项目的启发。

星级按**对本项目的可落地程度**评定，不按论文本身影响力。五星表示可直接指导实现决策。各目录 README 里有完整的逐篇星级与可借鉴思路。

## 准入与置信度

- 顶会论文、官方实现和可复现代码优先。
- 新发布或缺少验证的材料标为谨慎，只作为思路参考。
- 研究结论必须在正式设计文档中注明采用、保留或拒绝的理由。
