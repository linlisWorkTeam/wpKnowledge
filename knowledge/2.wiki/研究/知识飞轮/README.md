# 知识飞轮

轮次循环、状态推进、停止与回退这一段的调研材料。对应 `workflow` 模块与 `evaluation` 阶段的停止判定，是「评测产出事实、飞轮决定下一步」里的决策侧。

星级按**对本项目的可落地程度**评定，不按论文本身影响力。五星表示可直接指导实现决策。

## 缺口对照

项目当前未实现：保留历史最佳、关键回归回滚、停滞转 `LOW_CONFIDENCE`、自动清理、成本预算、停滞策略、历史最佳回退。

`ROLLING_BACK` 状态已存在、迁移边已连通，选择逻辑未实现。DGM 篇直接对应这一处。

## 怎么用这批材料

- **要补回退逻辑**：DGM 篇给出归档与父代选择，与 `Domain.ts` 的状态机对照看
- **要补成本与停滞**：搜索预算篇先做观测再定阈值的分步做法
- **要改 corrections 取舍**：GEPA 篇的逐测试项覆盖度加权与 `Correction.schema.json` 对照看

对应设计文档见 [`../../设计/知识飞轮实现方案.md`](../../设计/知识飞轮实现方案.md) 与 [`../../设计/门禁与评测机制.md`](../../设计/门禁与评测机制.md)。
