# 知识生成

源码到知识文档这一段的调研材料。对应 `doc_gen` 阶段与 `candidate_knowledge` 质量判断，涉及模块 `agents/docGenAgent` 与 `knowledge`。

星级按**对本项目的可落地程度**评定，不按论文本身影响力。五星表示可直接指导实现决策。

## 怎么用这批材料

- **要设计文档结构**：EGO-Prompt 篇给出可定位的关系表示，与本项目 `KnowledgeDocument` 的正文结构直接相关
- **要控跨文档一致性**：RepoDoc 与 Remember Your Trace 两篇提供图传播与记忆两种路线
- **要组织生成材料**：LLM 如何理解代码仓库、大语言模型与 API 文档两篇说明结构注入的实际收益边界

对应设计文档见 [`../../设计/知识飞轮实现方案.md`](../../设计/知识飞轮实现方案.md)。
