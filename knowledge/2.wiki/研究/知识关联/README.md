# 知识关联

外部知识关联这一段的调研材料。对应 `association` 模块与 `Association.md` 的 IO-23。

## 当前状态：功能延期

用户已明确跳过外部知识关联，当前阶段不实现，也不作为单 Agent 开发或飞轮验收的前置条件。本目录的材料保留供后续恢复该功能时参考。

已确认的范围约定：

- 外部知识由用户提供文档或指定已有知识库，候选关联目标必须来自这个范围
- 不能将指定知识库的授权扩大为全局文件读取或任意互联网搜索
- 关联判断角色、关联索引契约与检索接线均留待后续阶段
- 关联不改变每次飞轮只修订一份文档的约定，也不扩大 CodeAgent 的读取白名单

IO-22 的文档描述、YAML 头与渐进加载索引不属于本目录范围，那些归知识索引。
