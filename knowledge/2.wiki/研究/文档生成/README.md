## 怎么用这批材料

- **要设计知识文档结构**：EGO-Prompt 篇给出关系中间层与受约束算子的具体映射
- **要做增量同步**：RepoDoc 的图传播更新思路
- **要论证知识质量的价值**：RepoRepair、API 文档两篇形成正反证据
- **要多角色分工参考**：DocAgent 的角色划分与 DocGen 的 Worker 结构对照
