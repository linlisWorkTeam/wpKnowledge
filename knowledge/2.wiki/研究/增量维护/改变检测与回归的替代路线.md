# 改变检测与回归的替代路线

## 基本信息

这一篇集中收录几条方向相关但**适用性需打折**的材料，避免它们混在主线里被误当成可用方案。每条都给出「能借什么」与「为什么不能直接用」。

## 一、依赖感知的增量搬迁（DepWareTrans）

| 项目 | 内容 |
|---|---|
| 链接 | [arXiv:2608.14128](https://arxiv.org/abs/2608.14128) |
| 标题 | DepWareTrans: Dependency-Aware Incremental Repository Migration across Co-executable Languages |
| 发布 | 2026-08 |

**它做什么**：跨语言做仓库级迁移，把改动限制在依赖闭包内，而不是整体重写。

**能借的思路**：**「改动范围按依赖闭包收敛」这个原则**。一次变更不需要处理全部，只需要处理传递依赖闭包。这条原则与本项目增量更新的范围判定同构。

**为什么不能直接用**：目标是语言迁移，输出是迁移后的代码，不是知识文档。它的「影响范围」是编译依赖，本项目是知识引用。

**该收进哪里**：思路参考。若项目将来要做依赖闭包算法，可回看。

## 三、JavaScript 的变更影响推荐（Change Impact Recommendation for JavaScript）

| 项目 | 内容 |
|---|---|
| 链接 | [arXiv:2606.21187](https://arxiv.org/abs/2606.21187) |
| 标题 | Change Impact Recommendation for JavaScript: Lessons from History and Runtime Analysis |
| 发布 | 2026-06 |

**它做什么**：用历史与运行时数据为 JavaScript 项目推荐变更影响范围。

**能借的思路**：**两条独立信号源（历史 + 运行时）互相校验**。单一信号容易漏，两类信号覆盖的范围不同。

**为什么不能直接用**：语言绑定 JavaScript 生态，依赖运行时插桩。本项目的目标语言与运行环境不同，且知识文档层面没有运行时数据。

**该收进哪里**：思路参考。

## 四、缓存复用的安全边界（Grounded Cache Routing）

| 项目 | 内容 |
|---|---|
| 链接 | [arXiv:2605.27494](https://arxiv.org/abs/2605.27494) |
| 标题 | Grounded Cache Routing for Retrieval-Augmented Generation: When Is It Safe to Reuse an Answer? |
| 发布 | 2026-05 |

**它做什么**：判断检索增强生成里，一个已有答案在什么条件下可以安全复用。

**能借的思路**：**「能不能复用」需要显式判据，不能默认可以。** 这篇把「什么时候复用是安全的」当成独立问题来研究。本项目做增量更新，本质上也一直在复用未变化的部分，同样需要「复用安全」的判据。

**为什么不能直接用**：对象是 RAG 的问答缓存，不是文档内容更新。判据建立在其问答场景的grounding 条件上。

**该收进哪里**：思路参考，但与增量更新的「什么可以不重算」这个问题直接同构，值得在定方案时回看。

## 五、概念漂移检测（多条）

检索命中一批概念漂移（concept drift）检测的方法与评测论文，涉及：

- `2606.20216` 基于学习者的概念漂移检测
- `2606.07789` 概念漂移检测方法的评测与基准框架
- `2605.31186` 分类准确率能否代表概念漂移检测质量

**它做什么**：数据流场景下检测数据分布的变化。

**能借的思路**：**「漂移检测本身需要被评测」这个意识**，以及漂移检测有不同粒度和延迟的取舍。本项目的知识漂移如果需要度量，可以参考它的评测框架思路。

**为什么不能直接用**：概念漂移的对象是数据分布，本项目的「漂移」是知识与源码的不一致。两者只是**恰好共用了 drift 这个词**，数学框架完全不同。

**该收进哪里**：术语辨析用。**不要因为关键词匹配就把这类材料当成方案依据**，这是检索噪声。

## 收束

上面五条里，真正值得进方案层的只有两条原则：

1. **改动范围按依赖闭包收敛**（第一条）
2. **「可以复用」需要显式判据**（第四条）

其余三条是背景或需转译。本目录的主线方案以 [Grounded Claims 有据断言](Grounded%20Claims有据断言.md) 与 [行范围重定位](行范围重定位.md) 为准。
