## 3. 端到端实测（真 LLM）

### 3.1 全量知识场景（run_llm_full）

- 输入：tiling 模块完整知识文档（141 行，OKF 格式，带 sources 溯源）
- 结果：**一轮通过**，8/8 用例

```json
{
  "round": 1, "compile_ok": true,
  "passed": 8, "total": 8, "confidence": 1.0,
  "reps": {"count": 5, "mean": 1.0, "variance": 0.0, "min": 1.0, "unstable": false},
  "similarity": 0.2477, "decision": "pass",
  "attribution": "置信度 1.00，相似度 0.25", "weak_spots": []
}
```

### 3.2 陈旧知识场景（run_llm_stale）

- 输入：含过时接口信息的知识文档（模拟文档滞后）
- 结果：一轮通过，8/8，similarity 0.35（仍远低于抄源码基线 ~0.73，判为独立编写）

### 3.3 知识质量观察

LLM 知识生成在文档中主动标注了 4 处源码缺陷（`totalLength=0` 除零、`uint32_t` 溢出、`tailNumLastCore` 非均匀分配语义、核数超硬件），并给出使用建议——知识不仅复述，还能反哺源码质量。

## 4. 关键验证点（防作弊与可靠性）

| 验证点 | 结果 |
|--------|------|
| 知识文档不含源码原文 | ✅ 特征串泄漏检查零命中；伪代码围栏内算法描述合规 |
| Coder 物理隔离源码 | ✅ 沙箱白名单（knowledge/interfaces/work 只读，src_dir 硬禁止），`..` 穿越 resolve 拦截 |
| 写保护 | ✅ SHA-256 前后校验，越权修改即 ProtectionMismatch |
| 重复评测稳定性 | ✅ 5 次均值±方差，禁取最好成绩；方差>0.02 → UNSTABLE 走迭代 |
| 相似度定位 | ✅ 仅进归因诊断，不参与门禁判定（LLM 0.25-0.35 vs 抄源码 0.73 分得开） |
| 修订闭环（历史验证） | ✅ 缺陷注入后 R1 confidence 0.00 → 修订 → R2 1.00 |
