# 判断：soul 在下一版本的优先级（问 5）

> 快照 2026-08-23。结论：**soul 不是下一版全局的 top1，但是"体验层"的 top1；全局 top 是 Connecter 生产化 + A2A/MCP 服务器面。二者不冲突，soul 可以并行先行。**

---

## 1 · 判断依据：先看 omp 的棋盘

本知识库的战略文件给过五张牌（[05-joint-thinking](../../调研/clowder-ai调研/05-joint-thinking.md)、[06-strategy-thinking](../从0搭建MultiAgent平台/06-strategy-thinking.md)）：

| 牌 | 内容 | 优先级（当时） |
|---|---|---|
| 客厅牌 | 群聊 + 任务可见性 + 审批 | 常做 |
| 总机牌 | A2A 服务器面 + MCP 客户端 | P1 |
| 网络牌 | Connecter 跨站互通 | P1–P2 |
| 灵魂牌 | 通用 soul 规格 + MBTI 皮肤 + 关系资产可带走 | P2–P3 |
| 生态牌 | 开源门面 + 走出去 + 集成 dsh | 常做 |

而 **Connecter P0-P3 已经本地验证通过**（[实施状态](../../规划/Connecter%20P0-P3实施状态.md)，49 个 release gate 一次通过、两轮数十分钟联邦 soak 通过、恢复/灾难门禁通过，缺的是 72h soak 与真双机验收）。所以下一版（"下一代 OMP / ohMyAGI"）的棋盘是：

1. **让 Connecter 真正生产可用**（72h soak、HTTPS/mTLS、双机验收）——网络牌收尾；
2. **环3 协议层：A2A `tasks/send` 服务器面 + MCP 客户端**——总机牌，让任何 Agent（包括 clowder 的猫）能入群；
3. 体验与留存：soul、主题/皮肤商店、群聊打磨。

## 2 · 为什么 soul 不是全局 top1（四条理由）

1. **soul 不解决"任务正确性"**。它是壳不是电梯：换再多人格，agent 写错代码、任务状态机丢消息的问题不会消失。agent 平台的信任地基是可靠性；地基不稳时，人格化功能反而容易成为"花架子"的注脚。
2. **人格化的负面体验放大效应**。人格产品一旦不稳定/失忆/说错话，用户的失望是加倍的（期待越高摔得越疼）。clowder 的 soul 假设是否成立尚无公开数据，但即使成立，也需要 Threads/互审/SOP 这类地基先立住。
3. **soul 的舞台是群聊**。群聊还不够舒服时，soul 无从表现；反之群聊形态成熟后，soul 是"锦上添花"里的最高性价比。
4. **soul 是留存杠杆，不是拉新杠杆**。先解决"别人为什么来"（总机/网络/生态），再解决"来了为什么留下"（soul/记忆/皮肤）。

## 3 · 那什么更重要：三个 top 的真实排序

| 序 | 事项 | 为什么 | 性质 |
|---|---|---|---|
| 1 | **Connecter 生产化 + 环3 A2A/MCP 服务器面** | 这是 omp 唯一能"跑在 clowder 前面"的维度（跨机、家间互通）；别人没有，且已投入大半 | 差异化地基（网络牌+总机牌） |
| 2 | **群聊可靠性/可观测性打磨**（多用户、审批流、任务回溯） | 客厅的基本盘，"最舒服的 AI 协作界面"的承诺 | 基本盘 |
| 3 | **soul（体验层 top1）** | 留存第一杠杆、品牌抓手；成本最低、隔离最好、可并行 | 体验增量 |

## 4 · 但 soul 应该"先行发布"：三个实操理由

1. **工作量小（估，待基线）**：最小 soul 规格（soul.json + 3 个 markdown）+ 首发子集 8 个（6 工程 + 2 MBTI）+ 建群推荐，是"一个功能"的体量，不是"一个平台"的体量；OpenPersona/soulspec 把格式都开好了，我们只做绑定与注入。**拆法**：P0a（格式+绑定+注入+卸载-暂不导出）/ P0b（切换+handoff+导出+推荐），各自可独立发布。
2. **基本并行**：soul 注入点在上下文前缀，不碰任务状态机，不依赖 Connecter 的核心执行链；但**换 soul 的审计在 P0 用本地 SQLite 事件表先行**，Connecter 审计集成放 P1/P2（避免 P0 被网络牌阻塞）。
3. **品牌叙事**：下一代叫 "ohMyAGI"——"AGI"需要一个有名字、看得见的人格来立住叙事。一个能换肤、能卸载、能带走的 soul，比一百个 roadmap 词条都更接近"产品性格"。

## 5 · 推荐结论（一句话）

> **把 soul 排进下一版，但排在 Connecter 生产化与 A2A 服务器面之后；作为"体验层 top1、全局第三"并行开工，用"规格 + 预制 + 建群推荐"的 MVP 抢在下一个发布窗口上线**——它验证了 soul 链路，也为 ohMyAGI 的品牌立了名，同时不占用总机/网络的工程资源。
