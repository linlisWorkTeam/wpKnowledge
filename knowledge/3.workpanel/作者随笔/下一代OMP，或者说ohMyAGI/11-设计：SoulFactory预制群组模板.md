# 设计：SoulFactory 预制群组模板（05 章细化稿）

> 快照 2026-08-23。承接 05 章"预制群组 = 灵魂生产线"。本篇把 SoulFactory 群模板写成可直接开工的规格：角色、契约、状态机、门禁与验收。它是 ohMyAGI 官方第一个预制群组，也是"引导用户建群 → 生产 soul → 商店发布"闭环的第一条生产线。

---

## 1 · 群模板总览

```
群名：🧪 SoulFactory（soul 生产线）
群气质 soul：求真务实（fact-check 文化，借鉴 09 章 research-bibliophile 的硬边界）
触发：@soulfactory 制造<输入>；或拖入资料包
```

| 角色 | 建议 soul | 职责 | 输入 → 输出 |
|---|---|---|---|
| **采集员** | `bookworm-miner`（书虫研究员变体） | 归拢资料、去重、标注来源（L1 原文/L2 转述/L3 推断），写 `intake/` 清单 | 资料包 → 已标注语料库 + 覆盖报告 |
| **提炼师** | `distiller`（提炼师，新 SKU） | 4 维提取（思维/说话/记忆锚点/边界）→ `draft/soul-draft.md` | 语料库 → 人格草稿（含证据分级） |
| **评审员** | `review-hawk`（评审鹰，09 章已有） | 对照门禁打分、挑"无证据的断言"、给修改意见 | 草稿 → 评审报告 + 修改意见 |
| **发布员** | `release-mc`（发布司仪，09 章已有） | 生成 soul 包（soul.json + SOUL.md + 头像）、版本号、写商店描述 | 定稿 → 商店 soul 发布 / 建群推荐可用 |

> 注：`bookworm-miner` 与 `distiller` 为**生产线专用 SKU**（09 章 12 款货架之外，P2 随本群模板一同定义；不进建群推荐）；提炼维度模板（工程/文化/导师）至少各给一份样例。

**人类（雇主）**：只在"评审"阶段出现——批准或否决（人在环，对标 06 章确认卡）。

## 2 · 工单状态机（每单一个 thread / 消息线）

```
待采集 ──采集完成──▶ 待提炼 ──草稿完成──▶ 待评审 ──通过──▶ 待发布 ──发布──▶ 已发布
                      │                  │   └─退回──▶ 待提炼（带评审意见）
                      └─缺料/否决────────▶ 已关闭
```

- 每张工单：`SoulFactory/<工单号>/` 目录（intake/ + draft/ + review/ + release/）；
- 状态变更必须可见（群内消息 + 卡片），全程可回溯（对齐 omp"群 = 治理平面"）；
- 人类否决留存理由（教训库，对齐 clowder LL-### 文化）。

## 3 · 门禁（复用知识飞轮的脚本与阈值）

| 门 | 检查 | 阈值/标准 | 复用 |
|---|---|---|---|
| 结构门 | soul.json 必填字段、spec 版本、文件齐全 | schema 校验通过 | `endlessWpKnowledgeRunner` ingest 的 schema 校验 |
| 溯源门 | 每段人格都有 L1-L4 标注；L1 占比 | L1+L2 ≥ 40% | 飞轮 sources 字段机制 |
| 安全门 | prompt 注入/越权指令扫描 | 0 高危（对标 soulscan 53 模式） | 新增脚本（首版可手工 checklist） |
| 一致性门 | 3 模型抽样对话，风格漂移评估 | 漂移 ≤ 门槛 | 飞轮评测框架 + [Persona Fidelity](https://zenodo.org/records/18849974) 简化法 |
| 总分门 | 综合分（复用飞轮评分信号） | score ≥ 70 才 verified（对齐飞轮门禁） | 飞轮 `fw_score` 逻辑 |

## 4 · 与建群推荐/商店的关系

- **SoulFactory 是 P2"厂"的第一个预制群组**，同时验证两条链路：预制群组体系（05 章）与流水线生产（问 6）；
- **产出归属**：生产线产出 = **官方候选**，经 12 章门禁后按等级进"官方精选层"或"社区层"；`factory:needed` 打标只表示"生产方式"，不表示"归属层级"（官方═人工产出与工厂产出一视同仁地过门禁，权限与 KPI 按最终所在层级算，详见 13 章）；
- 产出物直接进入 09 章货架门禁与商店；生产线本身可被定制：换提炼维度模板（工程/文化/导师），即"定制 workflow"的开放点（05 章定制点 ②）。

## 5 · 验收标准（P2 完成判据）

1. 官方 5 个 SKU 的生产时间降到"喂料 1 小时 + 人确认 10 分钟"（**基线"人写 2 天"须先用真实计时定标，本数字为估量**）；
2. 流水线产出的 soul 通过全部门禁的比例 ≥ 60%（其余被评审员拒回，正常；同为估量，P2 开跑后按实调整）;
3. 社区能用同一群模板开第二条生产线（模板可复制），并发布第 1 个社区 soul。

## 6 · 一句话

> SoulFactory = **把 05 章的流水线变成 omp 里一个可复制的预制群组**：四个角色四种 soul、一张工单状态机、五道门禁全复用飞轮——它同时是"预制群组体系"的试验田和"填货架"的生产车间。
