## 标题候选

《让每个 Agent 有名字、有性格、有分寸 —— ohMyAGI 的 soul》

## 正文（约 800 字）

### 我们相信三件事

1. **人不是在跟工具协作，而是在跟"人"协作。** 多 Agent 平台的值钱之处不只是"能并行干活"，而是"像一支队伍那样相处"——有人盯进度、有人挑毛病、有人写文档、有人唱反调。
2. **人格要能带走。** 你喜欢的性格、沉淀的经历、养成的分寸，应该跟着你走——换机器、换站点、换平台，而不是被关在某个进程里。
3. **人格要有规矩。** 会说话不难，难的是"一直是他"。我们把人格的评测做成硬门禁：能上架的 soul，都是验证过一致性、可追溯、有边界的。

### soul 是什么

soul 是一个**可携带、可加载、可演化、可卸载的稳定人格包**：一份声明（谁）、一份人格（性格与分寸）、一套规则（怎么干活）、一条记忆通道（记得什么）、一份活性（什么时候主动出现）。

它挂在"群"与"成员"两层：一个群可以有团队气质（严谨冲刺型、快速原型型……），群里的每个 Agent 也可以有自己的性格（评审鹰、架构军师、文档工匠……）。换群 = 换文化；换掉成员 = 换人但不换能力。

soul 是壳，不是电梯：它改变"怎么相处"，不改变"任务怎么执行"。卸载一个 soul，队伍照常干活——只是不再有性格。

### 我们怎么保证它可信

- **格式开放**：兼容 soulspec 生态，不发明私有格式；
- **评测门禁**：结构、溯源、安全、去重、时效五道静态关 + 跨模型保真、对话一致性、使用反馈三组动态关；
- **记忆与身份分离**：你是谁，只有你能改；经历会沉淀，但不会悄悄改写性格；
- **合规底线**：soul 定位为工作人格与团队气质，不做情感陪伴。

### 怎么开始

- **开箱**：12 个首发 soul（评审鹰、架构军师、文档工匠、测试鹰眼、安全卫士、PM 管家……），建群时三选一，也可以一个都不要；
- **养**：和你的队伍多聊几周，我们会把"团队的气质"蒸馏成草稿卡片，你点头才生效；
- **造**：SoulFactory 预制群组让任何人都能量产 soul；你也永远可以把 soul 导出带走；
- **回**：喜欢谁、改过谁，都可以回灌给社区（署名 + 徽章），让好性格被更多人用上。

### 一句话

> 我们不想造"更聪明的工具"，我们想造"值得共事的队伍"——而 soul，是这支队伍的第一张名片。
