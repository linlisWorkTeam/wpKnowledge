# workpanelConnecter

WorkPanelConnecter 独立知识域，与 `workpanel/` 平级。这里记录 Connecter / Connecter Host 自身的设计、实现证据、竞品和跨平台适配研究，不把它混入 WorkPanel 应用层报告。

## 目录

- `docs/workpanel-connecter-analysis-report.md`：长期维护的综合入口。
- `docs/2026-08-22-design-and-evolution.md`：设计理念、当前架构与演进路线。
- `docs/2026-08-22-competitive-analysis.md`：市场竞品与替代/互补关系。
- `docs/2026-08-22-clowder-integration-analysis.md`：基于 Clowder AI 当前代码的成本、必要性和双平台连接结论。
- `docs/2026-08-22-documentation-consistency-audit.md`：仓库全文档与代码一致性审查、治理规则和证据边界。
- `notes/2026-08-22-research-evidence.md`：commit、命令、来源和未验证边界。

报告必须区分“代码已实现”“本地门禁通过”“外部环境验收通过”和“研究推断”。
